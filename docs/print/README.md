# Print materials

Two flyers, generated by `build.py`. Edit the Python, never the HTML — the HTML
is regenerated and overwritten.

```bash
cd docs/print && python3 build.py
```

| File | Size | QR points to | Use |
|---|---|---|---|
| `voice-lessons.html` | Letter, 8.5×11 | `/voice-lessons` | Corkboards, coffee shops, music stores, churches, VFW halls |
| `band.html` | Letter, 8.5×11 (or 4×6) | site root | Venues, promoters, merch table, handing out at shows |

## Printing

Open the file in Chrome → **Cmd-P** → Letter → Margins **None** → **Background
graphics ON**. That last one is not optional: without it the page prints white
and the gold text disappears.

`band.html` also does a 4×6 handout — change `<body class="letter">` to
`<body class="card">` and print at 4×6. The card is sized separately, so it is
not just the letter sheet shrunk.

## The tear-off tabs

`voice-lessons.html` ends in ten tear-off tabs, each with the phone number. Cut
up the dashed lines with scissors before pinning it — someone takes the number
without having to write anything down, and the flyer keeps working after they
walk away. That is most of the value of a board flyer.

## About the QR codes

Generated locally with `segno` at error-correction level **H** (~30% of the code
can be damaged and still scan), and inlined into the HTML as SVG. That means:

- Each flyer is one self-contained file. Email it to a print shop and it works.
- No QR is ever fetched from a third-party generator, and no URL of ours is
  typed into an online tool.
- The code is vector, so it stays sharp at any print size.

**Both codes were verified by decoding them back out of a rendered image**, not
just assumed correct. If you change a URL in `build.py`, re-render and scan the
result with a phone before printing a stack.

One trap worth knowing: `segno` emits an SVG with `width`/`height` but no
`viewBox`. Sizing that with CSS crops the canvas instead of scaling it — two of
the three corner squares vanish and the code silently stops scanning while still
looking like a QR code. `qr_svg()` adds the `viewBox` for this reason.

## Where the facts come from

Price, service area and discounts mirror `lib/lessons.ts`. The phone and email
are Malachias's own, also in that file. The Cashbox credit is the real March 2023
Artist Spotlight — see `docs/road-to-san-antonio/TODAY-CASHBOX.md`. If the price
or the campaign dates change on the site, change them here too; these files do
not read from the app.

## Known brand inconsistency

The emblem artwork reads **"Christian Rock · Veteran Spirit · Faith on Fire"**,
while the site writes **"Veteran Mission"** in seven places. The flyers follow the
site. Worth settling on one at some point.
